Operacion diaria

Como se mueve el trabajo del empleado

El sistema debe ayudar a ver con claridad en que etapa esta cada equipo y que decisiones faltan para cerrar el servicio.

01 Recepcion

Se registra el equipo, se vincula al cliente y se crea la orden con informacion inicial.

02 Soporte

El tecnico actualiza estado, diagnostico, observaciones y fecha estimada de entrega.

03 Cierre y venta

Se entrega el equipo, se gestiona cobro y se cruza con inventario o tienda si aplica.
